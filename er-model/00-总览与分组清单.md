## 六、关系证据分级标注约定（全库 0 外键，均按此标注）

| 标注 | 含义 | 强度 |
|---|---|---|
| `[注释明示]` | 字段 COMMENT 点名目标表（如 `关联 jf_xxx.id`） | 最强 |
| `[索引佐证]` | 字段建有 INDEX/UNIQUE，且 xxx_id 指向他表 PK | 强 |
| `[命名推断]` | 依据 `xxx_id` 命名 / 编码 / 语义推断 | 中 |
| `[语义推断]` | 仅依据业务语义（无 id/注释/索引） | 弱 |
| `[待确认]` | 目标表不存在或指向不明 | 存疑 |

- ER 图中每条关系均带基数（`1:1`/`1:N`/`N:M`）与上述依据标注；无外键一律标注为**推断关系**。
- 逻辑模型字段表列：`字段 | 类型 | 可空 | 默认值 | 键 | 含义`；可空列 `N`=NOT NULL；键列写作 `PK` / `UK` / `FK[目标表·依据]`。
