# D12 返利·对账·账单域 — 逻辑数据模型

> 数据源：`test_erp.sql`（唯一事实来源），逐表核对。全库无显式外键，"主/外键线索"与"关联"均为**推断**。

## 本域小结

- **三簇结构**：返利（结算主表 + 明细 + 审核 + 临时缓存）、对账单（主表 + 最终厂家关联 + 客户借贷流水 + 费项字典 + copy）、对账信息与交易。
- **多张问题表混入 A 级**：query_temp（临时）、copy1（完全冗余）应属 C 级；4 张表 id 非自增。
- **跨域依赖密集**：大量指向 D08 客户/贸易商、D01 销售订单、D09 商品、D06 费项、D07 退货、D03/D04 结算——本域是典型的"结算下游汇总域"。
- **一致性风险**：statement_fee_category ↔ jf_fee_category 双写靠人工；trade_records 审计字段命名与他表不同。
