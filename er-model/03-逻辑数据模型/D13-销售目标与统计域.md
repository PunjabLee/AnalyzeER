# D13 销售目标与统计域 — 逻辑数据模型

> 数据源：`test_erp.sql`（唯一事实来源），逐表核对。全库无显式外键，"主/外键线索"与"关联"均为**推断**。
> 共 **16 张表**。四张"月度分配宽表"均含 `jan`~`dec` × 3 指标（sales_target / actual_sales / target_completion_rate）的 36 列矩阵，本文对重复矩阵用统一说明压缩表达，其余字段逐一列出。

**月度矩阵通用列（M = jan|feb|mar|apr|may|jun|jul|aug|sep|oct|nov|dec）**：`{M}_sales_target` decimal(10,2) 可空、`{M}_actual_sales` decimal(10,2) 可空、`{M}_target_completion_rate` decimal(5,2) 可空——各月 3 列，合计 36 列，含义"该月销售目标/实际销售/完成率"。

## 本域小结

- **五级目标 + 三类表**：集团/贸易商/小组/个人/布种商品，每级"目标主表 + 月度分配 + 修改记录"，共 16 表。
- **月度矩阵反范式**：4 张宽表用 36 列表达 12 月，跨月统计困难。
- **数据质量**：2 张 import 表无主键；多张表 id/目标 id 用 varchar 存储与 bigint 主键类型不符；5 张修改记录表外键列命名各异（含带表名前缀 `jf_bloc_sales_target_id`）。
- **归属存疑**：`jf_trader_month_sales` 注释"该表可要可不要"。
