## 建模问题清单（本域）

- **P-D18-01 全非自增主键**：4 表 `id` 均非 AUTO_INCREMENT。
- **P-D18-02 立项宽表反范式**：initiation_analysis 单表 50+ 列混装项目/报价/地址/联系人；id 与文本双写（customer_id+customer）。
- **P-D18-03 拼写错误**：referenc_number（应 reference）、yarn_color_deth/blank_varies_deth（应 depth）。
- **P-D18-04 id 类型宽度不一**：proofing_number 的 dye_color_id/manufacturer_id/color_id/erp_color_id 用 `int`，其余 id 多为 bigint。
- **P-D18-05 delete_status 类型不一**：initiation_analysis/proofing_number.is_send 用 `tinyint`，多数用 `tinyint(1)`。
- **P-D18-06 列级字符集混用**：initiation_analysis.version 为 general_ci（表主体 unicode_ci）。
- **P-D18-07 注释含控制字符 / 旧系统遗留**：表 COMMENT 带 `\r\n`；proofing_number 含 erp_color_id 旧 ERP 迁移字段。
