## 本域小结（复核后）

- **两套体系**：质量标准（standard ↔ std_test_project ↔ test_project 三级 + 被 D14 `jf_basic_craft` 反向引用）、质量补损（compensation ↔ sales_mapping，经推断串联 D01/D04/D08/D09）。客诉字段全部在 `jf_quality_compensation`。
- **外部系统密集**：OA（oa_code）、CRM（crm_code/crm_complaint_code/crm_complaint_id/is_complaint_flow）、旧 ERP（test_project.project_id）——三处均为 `[注释明示→外部]`，**非本库表关系**。
- **复核证据修正**：`write_off_code` 无 COMMENT 明示目标表，维持 `[语义推断·待确认]`（不升级为确定关系）；人员字段三种表达（bigint id / 人名 / 人名文本）均外部/待确认，不臆造内部关联。
- **数据质量**：国家三字段冗余且目标双候选；std_test_project AUTO_INCREMENT=7.5e7；cus_id 命名不一致；crm_complaint_id varchar 存 id；judgment_conclusion 主键非自增；同域存在 quality_standard 同名异表族（D02/D09 各有 *_quality_standard）。
