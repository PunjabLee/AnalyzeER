## 1. 六类查询（UC1–UC6）黄金集构造规范

每条题目为结构化记录：
```
{ id, uc: UC1..UC6, query_nl, gold: {…可判定答案…}, source: [EvidenceSrc…], difficulty, tier_scope }
```
覆盖配额（MVP 建议，题量由 eval-gate 定）：

| UC | 类别 | 答案 gold 口径 | 主要依赖层 | 构造要点（基于实测锚点） |
|---|---|---|---|---|
| **UC1** | 查表 | 命中候选 `table_id` 集合 + 域/`tier` 过滤 | L1 BM25/FTS5 + 属性过滤 | 含按业务含义（「哪些表存贸易商额度」→ `jf_trader_quota`/`jf_trader_credit_quota_record`，D08）；含固化拼写原样可搜（`catregory`/`datat_dict`，D14） |
| **UC2** | 查字段 | 给定表→全列；或反向→含该列的表集 | L1 `IS_COLUMN_OF`/反向索引 | 正例 `jf_sales_order` 列（column_count 需 = DDL，注意 90 列）；反向「哪个表有 `sales_order_id`」跨域命中多表 |
| **UC3** | 查关系 | 边存在性 + `cardinality`+`evidence_level`+`source_ref` | L1 1 跳邻居 | 例 `jf_customer → jf_sales_order`（`01/D01` L171，`1:N [命名推断]`）；须附证据级 + 来源文件行 |
| **UC4** | 查影响 | 下游受影响表/字段清单（反向可达） | L2 反向 BFS/DFS + 置信剪枝 | 以 `jf_sales_order.status` 变更为例（§1.1）；默认 ≤3 跳，深度上限 [待确认] |
| **UC5** | 查血缘 | 正向/反向多跳链路（枢纽 `jf_sales_order`） | L1 多跳 + L2 摘要 | 表级 + 字段级引用/结构级；**变换/ETL 级不出题**（超范围 §2.3/R-9） |
| **UC6** | 按域检索 | 域内实体/关系/质量问题聚合摘要 | L2 社区/全局 + `BELONGS_TO_DOMAIN`/`HAS_ISSUE` | 例「D14 字典域有哪些实体和质量问题」；Issue 数须 = 实测归属，总量锚 27（见 §3） |

- **每类分布约束**：六类各 ≥1 硬正例 + 1 边界例（无路径/无节点须答「文档未记载/待确认」，**拒绝臆造兜底**，§6）。
- **tier_scope**：默认题目只考 A 级可遍历主语料（349）；B/C 默认降权，专项题需显式标 `include_*`。

## 2. 确定性基线测法（R-5：先测再决定引入向量/LLM）

**目的**：先量化「无 LLM、无向量」纯确定性栈的天花板，据此判断增益缺口。

### 2.1 被测基线（三档，逐档记录命中率）
1. **关键词/全文（BM25 via SQLite FTS5）**：`porter unicode61` 与 `trigram` 两种 tokenizer 各测（本机实测均可建表，见 `stack-options.md`）。
2. **图遍历（邻接表）**：1 跳邻居（UC2/UC3）+ 多跳 BFS/DFS ≤3（UC4/UC5），带 `confidence ≥ 0.45` 过滤。
3. **社区/全局摘要层**（M3 后追加，UC6/全局 sensemaking）：仅喂 `confidence ≥ 0.45` 边。

### 2.2 度量口径
- **命中率**：`Top-3 命中` = gold 关键实体/边/列 落在返回前 3。分别按 UC 统计，**阈值 [待确认]**（记实测值，不判达标）。
- **有出处率**（硬指标，非 [待确认]）：关系类（UC3/UC4/UC5）回答 **100%** 可回溯 `er-model/*` 文件+节（§1.5）；抽查断言每条 `RELATES_TO` 有 `SUPPORTED_BY`。
- **幻觉率**：返回实体/关系不在确定性来源内者计数，期望 **0**（LLM 层引入后专测）。
- **时延**：单跳 P95 / 多跳 P95（阈值 [待确认]）。
- **多跳截断可复现**：>3 跳须截断并给可复现路径（§6）。

### 2.3 通过/回退判据（供 eval-gate）
- 确定性基线跑通且数量等式闭合（§3）→ 记录各 UC 命中率作为 **M1 基线对照**。
- 某 UC 命中率显著低且缺口属「语义/全局」类 → 才评估引入向量/LLM（触发式，非默认，§1.2/R-5）。缺口性质与引入决策 → **[待确认]**。

## 3. 数量等式护栏（黄金集与装载共用，任一不闭合即阻断）

> 全部为 M0 对源文件独立 grep/wc/python 复算值；含 **三处口径差修正**（C-α、C-δ、C-ζ）。

| 断言 | 目标值（实测） | 取证 |
|---|---|---|

| A / B / C | 349（=332+OT17）/ 853（=450+275+128）/ 120（=117+3），Σ=1322 | `00` §三/§五/§8.1 + `_bak_`=117、`test_`=3 |

| `05` 核心关系线 | **33**，全 `\|\|..o{` | census §6（左可选最终正则复测，无左缺失变体） |

## 4. 与后续里程碑的评测衔接

- **M1**：跑 §2.1 档 1+2，出 UC1–UC3 + 表级血缘基线命中率 + 数量等式报告。
