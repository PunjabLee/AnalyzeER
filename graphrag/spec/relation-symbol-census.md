> 唯一写入者：M0。锚点：`design-plan.md` §4.1（关系符按实测变体匹配）、§3.2；R-3a。
> **本表是 M1 解析器正则的唯一依据**；与 `Agents.md`/`RUNBOOK` 约定冲突处**以本表实测为准**并留痕（§4）。
> **取证（口径 ξ · 全量，审计 P1-1 修订）**：对 `er-model/01-ER图/*`（20 篇）用**左基数标记可选**的连接符正则 `(?:\|\||\|o|\}o)?(?:--|\.\.)(?:\|\||o\||o\{|\|\{)` 提取 + `sort|uniq -c` → **456 条 / 12 种字形**（本会话两种独立方法复测一致：POSIX 最左最长 `-o` 全量扫描、行结构锚定「实体 连接符 实体:」）。旧版 `awk length==6`（仅 6 字符合规 token）系**子口径 ξ′ = 443 条 / 10 种**，其长度过滤曾静默丢弃 13 条「缺左基数标记」的非规范连接符（`..o{`×11、`..o|`×2，口径登记 **C-ζ**，见 §2.1）。Markdown `|---|` 分隔线不匹配完整正则（中段须恰为 `--`/`..`、右端须为基数形态），无需再按长度去噪。

## 1. 关系线格式（真源样例）

```
<左实体> <连接符> <右实体> : "<基数> [<证据标签>] <a.col -> b.id> […跨域…]"
例 01/D01 L171:  jf_customer ||--o{ jf_sales_order : "1:N [命名推断] order.customer_id -> customer.id (NOT NULL)"
```
- **规范连接符**为 6 字符、字符集 `| o { } . -`，左右由空格界定的独立 token；另有 13 条**缺左基数标记**的非规范形态（4/5 字符，§2.1）。
- **基数**（`1:N`/`N:1`/`1:1`/`N:M`）、**证据**（`[…]/…/…`）、**映射列**（`a.col -> b.id`）**全部在引号描述文本内**，非连接符。

按 Mermaid ER 语法全集（左 `|| \|o }o }|` × 中 `-- ..` × 右 `|| o| o{ |{`）**＋左缺失变体**逐组合实测，**0 出现**者：

| 0 出现（左-中-右） | 计数 | 备注 |
|---|---:|---|
| `\|\|--\|\|` | **0** | ⚠ `Agents.md` L94 称「1:1 用 `||--||`」——**实测 0**，禁据此建正则 |

| `\|\|..\|\|`、`\|\|..\|{` | 0 | 虚线一对一 / 虚线一强多 |

| `}o--\|\|`、`}o--\|{` | 0 | 零多 左到强单/强多（实线） |
| `}o..\|{` | 0 | 零多到强多（虚线） |
| `--o{`、`--o|`、`--||`、`--|\{`（**实线·左缺失**变体） | **0** | 左缺失形态**仅虚线**（`..o{`/`..o|`）实际出现，实线缺失不出现 |

- **正则最终形态（M1，审计 P1-1 定稿：左基数标记可选）**：

  (?:\|\||\|o|\}o)?(?:--|\.\.)(?:\|\||o\||o\{|\|\{)

  左 `(?:\|\||\|o|\}o)?` **可选**（缺省时命中 §2.1 两类，装载打 `malformed_connector=true`）；中段恰 `--`/`..`；右端 `o\{`/`o\|`/`\|\|`/`\|\{`（`\|\{` 实测 0，备而未用）。**cardinality/evidence/via_column 一律从描述文本解析**；`||--||`/`||--|{` 字形已含于字符集以备未来，但当前**不得假设其存在**。跨文本 `grep -o` 提取须防截尾假阳性（见 §2.1 陷阱注）。

## 5. 关联实测：基数文本 vs 连接符（关键，供 schema §2.1）

`01` 描述文本内**基数 token** 实测（`grep -rhoF`，注意同一行可含多个标签，为 substring 计数；分母为全量 456 条语料）：

| token | 出现 |
|---|---:|
| `1:N` | 232 |
| `N:1` | 128 |
| `1:1` | **19** |
| `N:M` | 3 |

- **结论**：`1:1` 在文本出现 **19 次**，而承载它的连接符 `\|\|--\|\|` 实测 **0 次** → 作者用 `\|\|--o{` 等连接符 + 文本 `1:1` 标注，连接符字形与基数**不对应**。→ M1 **cardinality 必须解析描述文本**，不得由连接符反推（与 §4.1「实线/虚线不对应证据强度」同理，扩展至基数）。
- **证据标签**亦以文本 `[证据]` 为准（实线仍可见 `[语义推断]`），映射见 `evidence-confidence-map.md`。
